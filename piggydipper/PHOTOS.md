# Swapping photos on the Piggy Dipper site

Every photo lives in the `img/` folder. To change one, save the new photo with the
exact same file name (for example `jana.jpg`) and replace the old file. Nothing else
needs to change. Day mode and night mode use the same photos.

Tips: use a JPG about 1800 pixels on the long side, and keep the same shape
(wide stays wide, tall stays tall) so it fits the frame.
